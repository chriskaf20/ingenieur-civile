# Points à vérifier

Statuts :
- `tranché` : référence retenue, utilisable comme telle.
- `hypothèse` : valeur sans source normative ou officielle. On l'emploie seulement comme hypothèse de projet, avec le badge « À vérifier ».
- `à confirmer` : référence fournie mais pas encore contrôlée sur le texte officiel.
- `ouvert` : rien n'est encore retenu.
