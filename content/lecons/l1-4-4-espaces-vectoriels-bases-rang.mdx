<Page etape="intuition" titre="L'intuition : deux directions pour aller partout">

Sur un terrain plat, un géomètre peut atteindre n'importe quel point en marchant selon **deux directions** qui ne sont pas parallèles : tant de pas vers l'est, tant de pas vers le nord. S'il n'a droit qu'à deux directions parallèles, il reste prisonnier d'une ligne.

Un nœud de charpente fonctionne pareil. Deux barres non alignées peuvent équilibrer **n'importe quelle** charge : on la décompose selon leurs deux directions. Deux barres alignées ne retiennent rien perpendiculairement à leur axe : le nœud descend jusqu'à ce que les barres ne soient plus alignées. C'est pourquoi un fil à linge tendu fléchit toujours sous le linge.

Le **rang** compte le nombre de directions, ou d'équations, vraiment indépendantes. Il dit si un système a une solution, une infinité, ou aucune, avant même de le résoudre.

<Encadre type="idee" titre="La question de cette leçon">
Trois équations à trois inconnues ont-elles toujours une solution unique ? Comment le savoir ?
</Encadre>

<Page etape="cours" titre="Le cours (1/2) : combinaisons, indépendance, bases">

### Vecteurs et combinaisons linéaires

Un vecteur de ℝⁿ est une liste de n nombres : une force (F<sub>x</sub> ; F<sub>y</sub>), les trois réactions d'un plateau, les quantités d'un métré. On les additionne et on les multiplie par des nombres. Une **combinaison linéaire** de u et v est un vecteur λ u + μ v.

### Famille libre, famille liée

Une famille est **libre** si aucun de ses vecteurs n'est une combinaison des autres. Sinon elle est **liée**. Dans le plan :

- u = (1 ; 2) et v = (2 ; 4) sont liés : v = 2 u, et det(u, v) = {nombre(dUV, 0)} ;
- u = (1 ; 2) et w = (3 ; 1) sont libres : det(u, w) = {nombre(dUW, 0)} ≠ 0.

### Base et dimension

Une **base** est une famille libre qui permet d'écrire tout vecteur. Dans le plan, toute base a **deux** vecteurs ; dans l'espace, **trois** : c'est la **dimension**. Trois vecteurs du plan sont donc toujours liés.

Les nombres λ et μ tels que F = λ u + μ w sont les **coordonnées** de F dans la base (u, w). Il y a une seule façon de les trouver : c'est un système 2 × 2 de déterminant non nul.

<Encadre type="exemple" titre="L'équilibre d'un nœud est un changement de base">
À un nœud de treillis, les deux barres donnent deux directions e<sub>1</sub> et e<sub>2</sub>. Équilibrer la charge F, c'est l'écrire F = λ e<sub>1</sub> + μ e<sub>2</sub> : les efforts dans les barres sont, au signe près, les coordonnées de F dans la base des barres. Si les barres sont alignées, ce n'est plus une base.
</Encadre>

</Page>

<Page etape="cours" titre="Le cours (2/2) : le rang et les solutions d'un système">

### Le rang

Le **rang** d'une matrice est le nombre de ses lignes indépendantes ; c'est aussi le nombre de ses colonnes indépendantes. Pour le calculer, on échelonne la matrice par le pivot de Gauss et l'on **compte les lignes non nulles**. Par exemple, la matrice (1 2 3 ; 2 4 6 ; 1 0 1) a pour rang {e1.rang} : sa deuxième ligne est le double de la première.

### Le théorème de Rouché-Fontené

Pour un système A x = b à n inconnues, on compare rg A et rg [A | b] :

| Rangs | Solutions | Ce que cela veut dire |
|---|---|---|
| rg A = rg [A \| b] = n | une seule | équations indépendantes et compatibles |
| rg A = rg [A \| b] < n | une infinité | une équation est la conséquence des autres |
| rg A < rg [A \| b] | aucune | une ligne dit « 0 = un nombre non nul » |

### En structures

Pour les réactions d'un plateau sur trois appuis (système M R = F de L1.4.3) :

- appuis en triangle : {libelle[natures[0].nature]} solution, la structure est **isostatique** ;
- appuis alignés, charge sur leur ligne : {libelle[natures[1].nature]} de solutions ; la statique ne suffit pas, il faut les déformations (structure **hyperstatique**, L2) ;
- appuis alignés, charge hors de leur ligne : {libelle[natures[2].nature]} solution ; le plateau bascule (**mécanisme**).

<Encadre type="retenir">
Rang = lignes non nulles après échelonnement. rg A = rg [A | b] = n : une solution ; rg A = rg [A | b] &lt; n : une infinité ; rg A &lt; rg [A | b] : aucune.
</Encadre>

</Page>

<Page etape="schemas" titre="Le schéma : trois systèmes, trois positions de droites">

<TroisCasDroites />

Chaque équation à deux inconnues est une **droite** ; une solution est un point commun aux deux droites.

**1.** Droites sécantes : un seul point commun. Les lignes de A sont indépendantes, rg A = 2.

**2.** Droites confondues : la seconde équation est le double de la première ; elle n'apporte rien. Tous les points de la droite sont solutions : rg A = rg [A | b] = 1 &lt; 2.

**3.** Droites parallèles : mêmes coefficients, seconds membres différents. Aucun point commun : l'échelonnement donne « 0 = {nombre(ePar[1][2], 0)} », et rg A = 1 &lt; rg [A | b] = 2.

</Page>

<Page etape="terrain" titre="Sur le terrain">

**Le contreventement.** Un cadre rectangulaire aux nœuds articulés est un mécanisme : ses équations d'équilibre n'ont pas de solution pour une charge horizontale, il se couche comme un parallélogramme. Une diagonale le transforme en deux triangles : les équations deviennent indépendantes et le cadre devient rigide.

<Encadre type="terrain" titre="Les hangars sans contreventement">
En RDC, des hangars et des abris de marché en bois ou en acier léger s'effondrent sous les rafales des orages tropicaux, parce qu'il manque des diagonales de contreventement dans la toiture ou les longs pans. Le calcul le dit avant l'accident : la structure est un mécanisme, son système d'équilibre n'a pas de solution.
</Encadre>

**Les messages des logiciels.** « Mécanisme », « structure instable », « matrice singulière » : ces messages signalent un défaut de rang. On cherche l'appui ou la barre manquante.

**Isostatique ou hyperstatique.** Quand il y a plus d'inconnues que d'équations indépendantes, la statique laisse une infinité de solutions : la bonne est celle qui respecte aussi les déformations. C'est le sujet du calcul des structures hyperstatiques (L2).

</Page>

<FicheMemo titre="Fiche mémo : bases et rang">

### Indépendance

libre : aucun vecteur n'est combinaison des autres · deux vecteurs du plan libres ⇔ det ≠ 0

### Base

libre + génératrice · plan : 2 vecteurs · espace : 3 · coordonnées uniques

### Rang

nombre de lignes non nulles après échelonnement · lignes indépendantes = colonnes indépendantes

### Rouché-Fontené (n inconnues)

$\operatorname{rg} A = \operatorname{rg}[A|b] = n$ : une solution · $= \ldots < n$ : une infinité · $\operatorname{rg} A < \operatorname{rg}[A|b]$ : aucune

### Structures

isostatique : une solution · hyperstatique : statique insuffisante · mécanisme : aucune

</FicheMemo>
