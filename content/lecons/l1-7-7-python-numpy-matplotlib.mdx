### Créer un tableau

```python
import numpy as np
L, q = 5.0, 12.0          # m, kN/m
x = np.linspace(0, L, 11) # 11 abscisses de 0 à 5 m
```

`linspace(a, b, n)` crée **n** valeurs régulières de a à b, **bornes comprises** : le pas vaut (b − a) / (n − 1), ici {reprFlottant((5 - 0) / 10)} m.

### Calculer sans boucle

```python
M = q * x * (L - x) / 2   # tableau de 11 moments (kN.m)
V = q * (L / 2 - x)       # tableau de 11 efforts tranchants (kN)
```

Chaque opération s'applique **élément par élément** : c'est la vectorisation.

### Le maximum et sa position

`M.max()` donne la plus grande valeur, {reprFlottant(e0.Mmax)} kN·m, et `x[M.argmax()]` l'abscisse où elle se trouve, {reprFlottant(e0.xMax)} m.

### Le tracé

```python
import matplotlib.pyplot as plt
plt.plot(x, M)
plt.title("Moment fléchissant")
plt.xlabel("x (m)")
plt.ylabel("M (kN.m)")
plt.grid(True)
plt.show()
```

<Page etape="erreurs" titre="Les erreurs fréquentes">

<Piege erreur="prendre trop peu de points.">
Avec 8 points au lieu de 11, aucun ne tombe au milieu : le maximum trouvé vaut {reprFlottant(e8.Mmax)} kN·m au lieu de {nombre(momentMaxTheorique(5, 12), 2)}. On prend assez de points, et un nombre impair pour avoir le milieu.
</Piege>

<Piege erreur="oublier les unités des axes.">
Le graphique d'un rapport sans unités ne se lit pas : xlabel et ylabel les portent.
</Piege>

<Piege erreur="utiliser une liste Python au lieu d'un tableau NumPy.">
`[0, 1, 2] * 2` répète la liste, il ne multiplie pas : `[0, 1, 2, 0, 1, 2]`. Il faut `np.array`.

<Console lignes={['>>> [0, 1, 2] * 2', '[0, 1, 2, 0, 1, 2]', '>>> np.array([0, 1, 2]) * 2', 'array([0, 2, 4])']} alt="La même multiplication par 2 : sur une liste Python, elle répète la liste ; sur un tableau NumPy, elle double chaque élément." titre="console Python" />
</Piege>

<Piege erreur="confondre linspace et arange.">
`np.arange(0, 5, 0.5)` s'arrête **avant** 5 ; `np.linspace(0, 5, 11)` inclut 5.
</Piege>
