<Page etape="projet" titre="Le corrigé (1/2) : le programme">

```python
import math

def reactions(L, q, charges):
    """Réactions RA, RB (kN) d'une poutre sur deux appuis de portée L (m),
    sous une charge uniforme q (kN/m) et des charges ponctuelles (F en kN, a en m)."""
    somme = q * L
    moment = q * L * L / 2          # moment de q L par rapport à A
    for F, a in charges:
        somme += F
        moment += F * a
    RB = moment / L
    RA = somme - RB
    return RA, RB

RA, RB = reactions(6.0, 8.0, [(20.0, 2.0), (15.0, 4.5)])
print(f"RA = {RA:.2f} kN")
print(f"RB = {RB:.2f} kN")
```

Il affiche RA = {formatF(r.RA, 2)} kN et RB = {formatF(r.RB, 2)} kN, comme la feuille : RA = {afficherValeur(v.B11, 2)} kN, RB = {afficherValeur(v.B10, 2)} kN.

```python
import math
from reactions import reactions

def test_charge_au_milieu():
    RA, RB = reactions(6.0, 0.0, [(20.0, 3.0)])
    assert math.isclose(RA, 10.0) and math.isclose(RB, 10.0)

def test_charge_sur_appui_B():
    RA, RB = reactions(6.0, 0.0, [(20.0, 6.0)])
    assert math.isclose(RA, 0.0, abs_tol=1e-12) and math.isclose(RB, 20.0)

def test_poutre_de_reference():
    RA, RB = reactions(6.0, 8.0, [(20.0, 2.0), (15.0, 4.5)])
    assert math.isclose(RA + RB, 83.0)
    assert math.isclose(RB, 251.5 / 6)
```

Les valeurs attendues viennent du calcul à la main de l'étape 1 : ΣF = {grandeur(r.somme, 2, 'kN')}, ΣM/A = {grandeur(r.moment, 2, 'kN·m')}.
