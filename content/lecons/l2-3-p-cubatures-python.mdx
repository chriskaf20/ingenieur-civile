On écrit d'abord les deux fonctions, chacune avec sa vérification de forme :

```python
def trapezes(aires, pas):
    """Volume par la méthode des trapèzes (moyenne des aires)."""
    n = len(aires) - 1
    return pas * (aires[0] / 2 + sum(aires[1:n]) + aires[n] / 2)

def simpson(aires, pas):
    """Volume par Simpson ; exige un nombre pair d'intervalles."""
    n = len(aires) - 1
    if n % 2 != 0:
        raise ValueError("Simpson : nombre d'intervalles impair")
    s = aires[0] + aires[n]
    s += 4 * sum(aires[1:n:2]) + 2 * sum(aires[2:n:2])
    return pas / 3 * s
```

Puis le test, et la lecture du fichier :

```python
import csv, math
from cubature import trapezes, simpson

# test : x² sur [0 ; 2], pas 0,5 → 8/3 exactement par Simpson
assert math.isclose(simpson([0, 0.25, 1, 2.25, 4], 0.5), 8 / 3)

deblai, remblai = [], []
with open("profils.csv", encoding="utf-8") as f:
    for ligne in csv.DictReader(f, delimiter=";"):
        deblai.append(float(ligne["deblai"]))
        remblai.append(float(ligne["remblai"]))

for nom, aires in (("déblai", deblai), ("remblai", remblai)):
    print(f"{nom:8s} trapèzes {trapezes(aires, 25):8.0f} m³  Simpson {simpson(aires, 25):8.0f} m³")
```
