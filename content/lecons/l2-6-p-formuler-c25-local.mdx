import { analyseGranulo, controleExposition, formulation } from '@/lib/calc/materiaux'
import { grandeur, nombre } from '@/lib/format'
import { ConeAbrams, GranuloSable, SourcesLocales, VolumesBeton } from '@/components/schemas/Materiaux2'
import { FractileBeton } from '@/components/schemas/Probas'
import { DiagrammeBarres } from '@/components/drawing/Diagrammes'

export const sFin = [60, 210, 330, 180, 80, 30, 10, 0, 0, 0]
export const sConc = [20, 40, 80, 120, 200, 260, 220, 0, 0, 0]
export const gFin = analyseGranulo(sFin, 100)
export const gConc = analyseGranulo(sConc, 60)
export const x = (2.5 - gConc.mf) / (gFin.mf - gConc.mf)
export const s = 5
export const fcm = 25 + 1.645 * s
export const donnees = { fcm: Math.round(fcm * 10) / 10, sigmaC: 45, G: 0.45, C: 350, air: 15, pSable: 40, rhoC: 3.1, rhoG: 2.6 }
export const f = formulation(donnees)
export const depart = { fcm: donnees.fcm, sigmaC: 45, G: 0.45, C: 350, air: 15, pSable: 40, rhoG: 2.6 }
export const expo = controleExposition(1, donnees.C, f.E)
export const parSac = { sable: f.sable / f.sacs, gravier: f.gravier / f.sacs, eau: f.E / f.sacs }
export const departExpo = { classe: 1, C: 350, E: Math.round(f.E) }

<Page etape="projet" titre="L'énoncé et les livrables">

Une école de six classes se construit à Kikwit (Kwilu). Les semelles et les poteaux sont en **C25/30**, consistance **S3**, fondations en classe d'exposition **XC2**. Le béton est fabriqué à la bétonnière ; on estime l'écart-type de production à {nombre(s, 0)} MPa (données de l'énoncé). Matériaux disponibles :

- ciment **CEM II 42,5** local (classe vraie retenue : 45 MPa) ;
- **sable de rivière** fin (analyse ci-dessous) et **sable de concassage** de grès ;
- **gravier concassé** de grès 4/20, de qualité moyenne (G = 0,45), masse volumique absolue 2,6 kg/L.

<SourcesLocales />

### Ce que tu rends

1. Les courbes granulométriques, les modules de finesse et la **correction** du sable.
2. La **résistance moyenne** à viser.
3. La **formulation** de 1 m³ et le **dosage par sac** de 50 kg.
4. La vérification de la **durabilité** (XC2) et le **plan de contrôle** du béton.

| Formulation | Dosage au jugé | Volumes absolus | Dosage par sac et correction d'eau |
