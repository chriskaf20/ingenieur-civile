<Page etape="intuition" titre="L'intuition : une balançoire qui revient">

Pousse une balançoire puis lâche-la : elle repart vers le milieu, le dépasse, revient… La force qui la ramène dépend de sa **position**, son inertie dépend de son **accélération** : l'équation fait intervenir la dérivée seconde. C'est le **second ordre**.

<MasseRessort />

Selon le frottement, le mouvement oscille longtemps, s'arrête vite sans osciller, ou entre les deux. Les mathématiques donnent exactement ces trois comportements, par le signe d'un discriminant.

<Page etape="cours" titre="Le cours (1/3) : l'équation homogène">

### L'équation caractéristique

Pour $y'' + p\,y' + q\,y = 0$, on cherche $y = e^{rt}$ : alors $y' = r e^{rt}$, $y'' = r^2 e^{rt}$, et l'équation devient $(r^2 + p r + q)\,e^{rt} = 0$. Il faut donc $r^2 + p\,r + q = 0$ : c'est l'**équation caractéristique**. Son discriminant $\Delta = p^2 - 4q$ décide de tout.

### Les trois cas

- $\Delta > 0$ : deux racines réelles $r_1, r_2$ ; $y = A e^{r_1 t} + B e^{r_2 t}$.
- $\Delta = 0$ : une racine double r ; $y = (A + B t)\,e^{r t}$.
- $\Delta < 0$ : racines complexes $\alpha \pm i\beta$ ; $y = e^{\alpha t}(A\cos\beta t + B\sin\beta t)$ : une **oscillation** de pulsation β dont l'amplitude évolue en $e^{\alpha t}$.

<Page etape="cours" titre="Le cours (2/3) : le second membre">

### Solution générale = homogène + particulière

Pour $y'' + p\,y' + q\,y = f(t)$, toute solution est la somme d'une solution de l'équation homogène (avec ses deux constantes) et d'**une** solution particulière de l'équation complète.

### Trouver une solution particulière

On la cherche de la même forme que le second membre :

- f constante = F : on essaie $y_p = C$, d'où $q\,C = F$, $C = F/q$ ;
- f polynôme : un polynôme de même degré ;
- f = F cos ωt : $y_p = a\cos\omega t + b\sin\omega t$.

Exemple : $y'' + 4y = 8$ a pour solution particulière $y_p = 2$, et pour solution générale $y = 2 + A\cos 2t + B\sin 2t$.

<Regle type="simplification">
Si le second membre oscille à la pulsation propre (ω = β avec α = 0), la forme proposée ne marche plus : c'est la **résonance**, où l'amplitude croît sans cesse. En pratique, l'amortissement la limite (L2.1.5, dynamique en M1.7).
</Regle>

</Page>

<Page etape="cours" titre="Le cours (3/3) : les conditions initiales">

### Deux constantes, deux conditions

La solution générale a deux constantes A et B. On les fixe par **deux** conditions : la position et la vitesse au départ, $y(0)$ et $y'(0)$, ou deux valeurs aux bords pour une poutre, $y(0) = 0$ et $y(L) = 0$.

### Un exemple complet

$y'' - 3y' + 2y = 0$, $y(0) = 1$, $y'(0) = 0$ : racines 2 et 1, $y = A e^{2t} + B e^{t}$. Les conditions donnent $A + B = 1$ et $2A + B = 0$, d'où $A = -1$, $B = 2$ : $y = 2e^{t} - e^{2t}$.

<Page etape="terrain" titre="Sur le terrain">

**Pourquoi l'ingénieur s'en soucie.** Une passerelle piétonne, un plancher léger, une tour : chacun a une fréquence propre. Si les pas des piétons, une machine ou le vent l'excitent à cette fréquence, la résonance peut rendre l'ouvrage inconfortable, voire dangereux. Le second ordre explique pourquoi on éloigne les fréquences et pourquoi l'amortissement compte.

<MasseRessort />

<Encadre type="terrain" titre="Les machines sur les planchers">
Un groupe électrogène ou une pompe posés sur une dalle la font vibrer à leur vitesse de rotation. On les pose sur des plots souples et l'on vérifie que la fréquence propre de la dalle est loin de celle de la machine.
</Encadre>

<FicheMemo titre="Fiche mémo : second ordre">

### Homogène

r² + p r + q = 0 · Δ = p² − 4q

### Trois formes

Δ &gt; 0 : A e^(r1 t) + B e^(r2 t) · Δ = 0 : (A + B t) e^(rt) · Δ &lt; 0 : e^(αt)(A cos βt + B sin βt)

### Avec second membre

générale = homogène + particulière (forme du second membre) · constante F : y_p = F/q

### Constantes

deux conditions, appliquées à la solution complète

</FicheMemo>
