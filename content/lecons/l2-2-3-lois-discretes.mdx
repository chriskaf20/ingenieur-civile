<Page etape="cours" titre="Le cours (1/3) : variable aléatoire, espérance, variance">

### La loi d'une variable discrète

X prend des valeurs $k = 0, 1, 2…$ avec des probabilités $P(X = k)$ dont la somme vaut 1.

### Espérance et variance

- espérance : $E(X) = \sum k\,P(X = k)$, la moyenne sur un grand nombre de répétitions ;
- variance : $V(X) = \sum (k - E(X))^2\,P(X = k)$ ; écart-type $\sigma = \sqrt{V(X)}$.

Ce sont les équivalents, pour une loi, de la moyenne et de l'écart-type d'une série (L2.2.1).

<Page etape="cours" titre="Le cours (2/3) : la loi binomiale">

### Quand l'utiliser ?

On répète **n** fois la même épreuve, **indépendamment** ; chaque fois, « succès » avec la probabilité **p**. X = nombre de succès suit la loi binomiale B(n, p) :

$$P(X = k) = \binom{n}{k}\,p^k\,(1 - p)^{n-k}$$

$\binom{n}{k}$ compte les façons de placer les k succès parmi les n essais : $\binom{10}{3}$ = {nombre(combinaisons(10, 3), 0)}.

### Moyenne et dispersion

$E(X) = n p$, $V(X) = n p (1 - p)$. Pour B(10 ; 0,05) : en moyenne 0,5 éprouvette faible ; P(X = 0) = {nombre(B10[0] ?? 0, 3)}, P(X ≤ 1) = {nombre(binomialeCumul(10, 0.05, 1), 3)}.

<Regle type="simplification">
Pour un prélèvement sans remise dans un petit lot, la vraie loi est hypergéométrique ; la binomiale est une bonne approximation quand l'échantillon fait moins de 10 % du lot.
</Regle>

<Page etape="cours" titre="Le cours (3/3) : la loi de Poisson">

### Les événements rares

Pannes de grue par mois, accidents sur un tronçon de route par an, défauts par mètre de soudure : le nombre d'événements, de moyenne λ, suit souvent la loi de Poisson :

$$P(X = k) = e^{-\lambda}\,\frac{\lambda^k}{k!},\quad E(X) = V(X) = \lambda$$

### L'approximation

Quand n est grand et p petit ($n \ge 30$, $p \le 0{,}1$ en pratique), B(n, p) ≈ P(λ = n p) : plus simple à calculer.

<BarresLoi probas={P05} titre="Poisson, λ = 0,5" couleur="var(--color-acier)" />

### « Au moins un »

P(X ≥ 1) = 1 − P(X = 0) : passer par le contraire évite une somme infinie.

</Page>

<FicheMemo titre="Fiche mémo : lois discrètes">

### Variable aléatoire

E(X) = Σ k P(X = k) · V(X) = Σ (k − E)² P(X = k)

### Binomiale B(n, p)

P(X = k) = C(n, k) pᵏ (1 − p)ⁿ⁻ᵏ · E = n p · V = n p (1 − p) · essais indépendants

### Poisson P(λ)

P(X = k) = e⁻λ λᵏ / k! · E = V = λ · B(n, p) ≈ P(n p) si n grand, p petit

### Réflexe

au moins un : 1 − P(X = 0)

</FicheMemo>
