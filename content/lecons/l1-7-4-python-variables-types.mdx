### Affecter une valeur

`b = 0.2` range la valeur 0,2 sous le nom `b`. Le signe `=` n'est pas une égalité mathématique : il **range**. On peut ensuite écrire `G = b * h * L * gamma`. Ce qui suit `#` est un **commentaire**, ignoré par Python : on y écrit l'unité.

```python
b = 0.2       # largeur (m)
h = 0.4       # hauteur (m)
L = 5.0       # portée (m)
gamma = 25    # poids volumique du béton armé (kN/m3)
G = b * h * L * gamma
print(G)
```

### Les opérations

`+ - * /` et `**` (puissance) suivent les priorités habituelles. Deux opérations utiles aux quantités : `//`, la **division entière**, et `%`, le **reste**. `math.ceil` arrondit vers le haut : pour {nombre(s0.masse, 0)} kg de ciment en sacs de 50 kg, il faut {s0.sacs} sacs.

### Afficher proprement

`print(G)` affiche la valeur brute : **{reprFlottant(G0)}**. Les flottants sont des approximations binaires :

<Piege erreur="écrire 0,2 au lieu de 0.2.">
`b = 0,2` fabrique un couple (0, 2), pas un nombre : la suite du calcul échoue ou donne n'importe quoi. Le séparateur décimal est le **point**.

<Console lignes={['>>> b = 0,2', '>>> print(b)', '(0, 2)', '>>> "25" + 5', 'TypeError: can only concatenate str (not "int") to str']} alt="Deux erreurs dans la console : 0,2 avec une virgule donne le couple (0, 2) ; additionner le texte 25 et le nombre 5 provoque une erreur de type." titre="console Python" />
</Piege>

<Piege erreur="mélanger texte et nombre.">
`"25" + 5` provoque une erreur de type. Un nombre lu au clavier ou dans un fichier est un texte : on le convertit avec `float(…)`.
</Piege>

<Piege erreur="comparer deux flottants avec ==.">
`0.1 + 0.2 == 0.3` vaut `False`. On compare avec `math.isclose` (L1.7.8).
</Piege>

<Piege erreur="choisir des noms obscurs.">
