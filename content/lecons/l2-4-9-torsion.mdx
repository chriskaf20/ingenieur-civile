<Page etape="cours" titre="Le cours (1/3) : contraintes de torsion">

### Hypothèses

Pour un arbre **circulaire**, les sections restent planes et tournent en bloc ; chaque rayon reste droit. Le glissement, donc le cisaillement, croît linéairement avec la distance r à l'axe :

$$\tau(r) = \frac{T\,r}{J},\qquad J = \frac{\pi(D^4 - d^4)}{32}$$

J est le **moment quadratique polaire**. Le maximum est au bord : $\tau_{max} = T\,D/(2J)$.

### Exemple

Arbre plein Ø 50 mm, T = 2 kN·m : J = {nombre(t0.J, 0)} mm⁴, $\tau_{max}$ = {nombre(t0.tauMax, 1)} MPa.

<ArbreTorsion T={2} D={50} tau={t0.tauMax} thetaDeg={t0.thetaDeg} />

</Page>

<Page etape="cours" titre="Le cours (2/3) : l'angle de torsion">

### La rotation

Sur une longueur L, la section d'extrémité tourne de :

$$\theta = \frac{T\,L}{G\,J}$$

G, le module de cisaillement, vaut $E/(2(1+\nu))$ : environ {nombre(Gacier, 0)} MPa pour l'acier (avec ν = 0,3).

### Unités

T en N·mm, L en mm, G en MPa, J en mm⁴ : θ en radians ; × 180/π pour les degrés. Pour l'exemple sur 1,5 m : θ = {nombre(t0.thetaDeg, 2)}°.

<FicheMemo titre="Fiche mémo : torsion">

### Polaire

J = π (D⁴ − d⁴)/32 · cercle plein π D⁴/32 = 2 I

### Contraintes

τ(r) = T r/J · τmax = T D/(2J), au bord

### Angle

θ = T L/(G J) · G = E/(2(1 + ν)) · acier ≈ 81 000 MPa

### Domaine

sections circulaires · tubes efficaces · profils ouverts souples

</FicheMemo>
