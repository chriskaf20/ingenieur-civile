import { MatIso } from '@/components/schemas/Vecteurs'

export const d = EXEMPLE_MAT
export const r = matHaubane(d)
export const env = enveloppeMat(d)
export const pire = matHaubane({ ...d, psi: env.psiMax })
export const tNord = Math.max(...r.haubans.map((h) => h.T))
export const vPire = Math.max(...pire.haubans.map((h) => h.V))
export const dirs = r.haubans.map((h) => `${nombre(h.phi, 0)}°`).join(', ')

<Page etape="projet" titre="L'énoncé et les livrables">

Une radio communautaire de Kisangani installe une antenne au sommet d'un mât. Le mât est tenu par **trois haubans** attachés à {grandeur(d.h, 0, 'm')} de haut et ancrés dans trois massifs de béton, à {grandeur(d.r, 0, 'm')} du pied, à 120° les uns des autres. On te demande les efforts qui serviront à choisir les câbles et les ancrages.

### Les données

- Directions des ancrages vues du pied du mât : {dirs} (comptées depuis l'est, dans le sens trigonométrique : 90° est le nord).
- Le vent sur l'antenne et le haut du mât est représenté par un **effort horizontal de {grandeur(d.H, 1, 'kN')} en tête**. Vent du nord : l'effort pousse la tête vers le sud, direction {nombre(d.psi, 0)}°.
- On ajoute {grandeur(d.marge, 0, 'm')} de câble par hauban pour les attaches et le tendeur.

Ces valeurs sont des **données de l'énoncé**. Sur un vrai projet, l'effort du vent se calcule selon l'EN 1991-1-4 (EC1-1-4), vu plus tard dans le cursus.

### Ce que tu rends

1. La longueur et l'inclinaison d'un hauban.
2. Les tensions des trois haubans par vent du nord.
3. La direction d'effort la plus défavorable et la tension maximale d'un hauban.
4. La compression ajoutée au mât et l'arrachement de l'ancrage le plus chargé.
5. La longueur totale de câble à commander.

<Regle type="simplification">
On néglige la prétension des haubans (en réalité, on les tend au montage), le poids des câbles (qui leur donne une légère flèche) et celui du mât. Un câble ne travaille qu'en **traction** : il ne peut pas pousser.
</Regle>

Les trois haubans ont la même tension maximale, {grandeur(env.Tmax, 2, 'kN')} : c'est logique, ils sont disposés symétriquement. Le cas « vent du nord », qui semblait le plus simple, sous-estime cette tension de {grandeur(variation(tNord, env.Tmax) * 100, 1, '%')}.

### Les efforts transmis

- **Compression du mât** : {grandeur(r.N, 2, 'kN')} par vent du nord, {grandeur(pire.N, 2, 'kN')} dans le cas le plus défavorable (deux haubans tirent vers le bas).
- **Arrachement de l'ancrage le plus chargé** : {grandeur(vPire, 2, 'kN')} vers le haut, plus une composante horizontale qui tend à le faire glisser vers le mât.
- **Câble** : {grandeur(r.cable, 2, 'm')} à commander, attaches comprises.

<Encadre type="attention">
Ces efforts restent ceux d'un modèle simplifié. Sur un vrai projet, on ajoute la prétension, on calcule le vent selon l'EC1-1-4 et l'on applique les coefficients partiels de l'Eurocode avant de choisir les câbles (selon leur notice) et de dimensionner les massifs d'ancrage.
</Encadre>
