import { EXEMPLE_SOLIVE, solive } from '@/lib/calc/rdm1'
import { grandeur, nombre } from '@/lib/format'
import { CisaillementRect, ContraintesFlexion, DiagrammesVM, PlancherSolives } from '@/components/schemas/Rdm1'
import { DiagrammeBarres } from '@/components/drawing/Diagrammes'

export const d = EXEMPLE_SOLIVE
export const s0 = solive(d)
export const sections = [[6.3, 17.5], [7.5, 20], [7.5, 22.5], [8, 25]]
export const essais = sections.map(([b, h]) => ({ b, h, r: solive({ ...d, b, h }) }))
export const choix = essais.find((e) => e.r.taux <= 1 && e.r.rapport >= 300) ?? essais[essais.length - 1]

<Page etape="projet" titre="L'énoncé et les livrables">

Une famille de Bukavu construit l'étage de sa maison avec un **plancher bois** : des solives posées entre deux murs porteurs distants de **4 m**, tous les **50 cm**, recouvertes de planches. Charges retenues (données de l'énoncé) : plancher et revêtement g = 0,6 kN/m², exploitation (habitation) q = 1,5 kN/m² <AVerifier note="A_VERIFIER.md n° 66 : charge d'exploitation des planchers d'habitation (EN 1991-1-1 tableau 6.2, catégorie A, et annexe nationale)" />. Bois local de poids volumique 5 kN/m³, E = 11 000 MPa ; contrainte limite retenue 10 MPa ; flèche limitée à L/300.

<PlancherSolives e={d.e} L={d.L} b={d.b} h={d.h} />

### Ce que tu rends

1. La **descente de charge** sur une solive (kN/m).
2. Les **diagrammes** V et M et leurs valeurs maximales.
3. La vérification de **flexion**, de **cisaillement** et de **flèche** pour plusieurs sections commerciales.
4. Le **choix** argumenté et un croquis coté.

<Regle type="simplification">
On travaille sans coefficients partiels ni coefficients de durée de charge et d'humidité du bois (kmod, γM de l'EN 1995) : c'est une vérification pédagogique. Le calcul réglementaire est fait en L3.
</Regle>
