Avec trois inconnues ou mille, la méthode est la même ; seule la patience change, et c'est pourquoi on la confie aux ordinateurs.

<Page etape="cours" titre="Le cours (1/2) : la méthode du pivot">

### L'écriture matricielle

Un système de n équations linéaires à n inconnues s'écrit **A x = b** : A rassemble les coefficients, x les inconnues, b le second membre. Pour calculer, on travaille sur la **matrice augmentée** [A | b] : chaque ligne est une équation.

### Les opérations élémentaires

Trois opérations ne changent pas les solutions du système :

1. **échanger** deux lignes : L<sub>i</sub> ↔ L<sub>j</sub> ;
2. **multiplier** une ligne par un nombre **non nul** ;
3. **retrancher** à une ligne un multiple d'une autre : L<sub>i</sub> ← L<sub>i</sub> − k L<sub>j</sub>.

### La méthode

1. On prend le premier coefficient de la diagonale, le **pivot**.
2. Sous lui, on annule chaque coefficient par L<sub>i</sub> ← L<sub>i</sub> − k L<sub>1</sub>, avec k = a<sub>i1</sub> / a<sub>11</sub>.
3. On recommence avec le pivot suivant, sur les lignes du dessous.
4. Le système devient **triangulaire** : on le résout par **remontée**, de la dernière inconnue à la première.

<EtapesGauss />

<Encadre type="exemple" titre="Le premier pas sur les tickets">
[2 1 | 25] et [1 1 | 15] : pivot 2, k = 1/2. L<sub>2</sub> ← L<sub>2</sub> − ½ L<sub>1</sub> donne [0 ½ | 2,5]. Donc y = 2,5 / 0,5 = {nombre(recu.x[1], 0)}, puis 2 x = 25 − {nombre(recu.x[1], 0)} et x = {nombre(recu.x[0], 0)}.
</Encadre>

<Regle type="simplification">
On traite ici des systèmes carrés (autant d'équations que d'inconnues) qui ont une solution unique. Les autres cas, sans solution ou avec une infinité de solutions, sont l'objet de L1.4.4.
</Regle>

</Page>

<Page etape="cours" titre="Le cours (2/2) : pivots nuls, arrondis, contrôle">

### Un pivot nul

Si le pivot est nul, on ne peut pas diviser par lui. On **échange** sa ligne avec une ligne du dessous dont le coefficient n'est pas nul. Pour 0 x + y = 2 et x + y = 3, on échange les deux lignes ; le système est alors déjà triangulaire : y = {nombre(swap.x[1], 0)}, puis x = {nombre(swap.x[0], 0)}.

<PivotNulEchange M1={[[0, 1, 2], [1, 1, 3]]} M2={[[1, 1, 3], [0, 1, 2]]} />

### Le pivot partiel

Un pivot très petit fait exploser les multiplicateurs k, et avec eux les erreurs d'arrondi. Les logiciels choisissent donc, dans chaque colonne, le coefficient **le plus grand en valeur absolue** comme pivot : c'est le **pivot partiel**.

<Regle type="art">
À la main, garde au moins quatre chiffres significatifs dans les étapes intermédiaires et n'arrondis qu'à la fin. Un arrondi trop tôt dans la première élimination se propage dans toutes les inconnues.
</Regle>

### Le contrôle

On **reporte** la solution dans les équations de départ : chaque équation doit être vérifiée, aux arrondis près. Ce contrôle prend une minute et détecte presque toutes les erreurs de signe.

### Le coût du calcul

Pour n inconnues, la triangulation demande environ n³ / 3 multiplications : quelques dizaines pour n = 3, mais {scientifique(1000 ** 3 / 3, 2)} pour n = 1 000. C'est rien pour un ordinateur, impossible à la main : on résout à la main les systèmes 2 × 2 et 3 × 3, et l'on comprend ainsi ce que fait le logiciel.

<Encadre type="retenir">
Pivot, élimination sous le pivot (sans oublier le second membre), système triangulaire, remontée, contrôle. Pivot nul : on échange les lignes.
</Encadre>

</Page>

<Page etape="terrain" titre="Sur le terrain">

**La composition des bétons.** Une méthode de composition (L2.6) fixe une courbe granulométrique de référence. Ajuster les proportions de plusieurs granulats pour s'en approcher est un système linéaire ; avec plus de tamis que de granulats, on cherche le meilleur compromis (moindres carrés), toujours par des calculs matriciels.

<Encadre type="terrain" titre="À la cimenterie">
Dans une cimenterie, comme celles du Kongo-Central, le cru est un mélange de calcaire, d'argile et de correctifs. Chaque matière apporte sa part de chaux, de silice, d'alumine et d'oxyde de fer : trouver les proportions qui donnent la composition visée est le même problème que notre mélange de granulats, avec plus d'équations.
</Encadre>

<CruCimenterie />

**Les logiciels de calcul.** Un logiciel de structure, de réseau d'eau ou de topographie résout des systèmes de milliers d'équations. Les méthodes qu'il emploie (Gauss avec pivot, Cholesky, méthodes itératives, L2.3.5) sont des variantes de ce que tu viens de faire à la main.

**La topographie.** Les mesures d'un cheminement ou d'un nivellement sont plus nombreuses que les inconnues. Leur compensation conduit à un système linéaire, résolu de la même façon.

<FicheMemo titre="Fiche mémo : pivot de Gauss">

### Écriture

A x = b · matrice augmentée [A | b] · une ligne = une équation

### Opérations permises

L<sub>i</sub> ↔ L<sub>j</sub> · L<sub>i</sub> × k (k ≠ 0) · L<sub>i</sub> ← L<sub>i</sub> − k L<sub>j</sub>

### Élimination

k = a<sub>ij</sub> / a<sub>jj</sub> · toute la ligne, second membre compris · pivot nul → échange

### Remontée

$x_n = b_n / a_{nn}$, puis on remonte ligne par ligne

### Contrôle

report dans les équations de départ · 4 chiffres significatifs minimum

</FicheMemo>

Résous : x + 2 y + z = 8 ; 2 x + y + z = 7 ; x + y + 3 z = 12.

<Indice>Pivot 1 : L<sub>2</sub> ← L<sub>2</sub> − 2 L<sub>1</sub> et L<sub>3</sub> ← L<sub>3</sub> − L<sub>1</sub>. Puis élimine y de la ligne 3 avec la nouvelle ligne 2.</Indice>

<Exercice n={3} niveau="difficile" titre="Un pivot nul">

Résous : 2 y + z = 7 ; x + y + z = 6 ; 2 x + y + 3 z = 13.

<Indice>Le premier pivot est nul : échange les lignes 1 et 2 avant d'éliminer.</Indice>

<Corrige>
L<sub>1</sub> ↔ L<sub>2</sub>, puis L<sub>3</sub> ← L<sub>3</sub> − 2 L<sub>1</sub> : −y + z = 1. Avec 2 y + z = 7 : L<sub>3</sub> ← L<sub>3</sub> + ½ L<sub>2</sub> donne (3/2) z = 4,5, donc z = **{nombre(ex3.x[2], 0)}**, y = **{nombre(ex3.x[1], 0)}**, x = **{nombre(ex3.x[0], 0)}**. Sans l'échange, la première division était impossible.
</Corrige>
