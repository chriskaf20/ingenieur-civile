import { bilanPoidsPropres, CHARGE_GLOBALE_NIVEAU, EXEMPLE_POIDS_PROPRES, memeOrdre, poidsDalle, poidsLineaire } from '@/lib/calc/ordres'
import { POIDS_VOLUMIQUE_BA } from '@/lib/calc/methode'
import { surfaceRectangle } from '@/lib/calc/unites'
import { grandeur, nombre, nombreCourt } from '@/lib/format'

export const { dalle, poutre, mur } = EXEMPLE_POIDS_PROPRES
export const rd = poidsDalle(dalle.Lx, dalle.Ly, dalle.e)
export const rp = poidsLineaire(poutre.L, poutre.b, poutre.h, POIDS_VOLUMIQUE_BA)
export const rm = poidsLineaire(mur.L, mur.e, mur.H, mur.gamma)
export const Sdalle = surfaceRectangle(dalle.Lx, dalle.Ly)
export const bilan = bilanPoidsPropres([rd.P, rp.P, rm.P], Sdalle)
export const pct = (x) => `${x >= 0 ? '+' : '−'}${nombre(Math.abs(x) * 100, 0)} %`

<Page etape="projet" titre="L'énoncé et les livrables">

Un client de Lubumbashi veut construire un petit bureau accolé à sa maison. Avant tout calcul de structure, le bureau d'études te demande les **poids propres** des trois éléments principaux :

- une **dalle** en béton armé de {nombre(dalle.Lx, 2)} m × {nombre(dalle.Ly, 2)} m et {nombre(dalle.e * 100, 0)} cm d'épaisseur ;
- une **poutre** en béton armé de {nombre(poutre.L, 2)} m, de section {nombre(poutre.b * 100, 0)} × {nombre(poutre.h * 100, 0)} cm ;
- un **mur** en blocs pleins de béton de {nombre(mur.L, 2)} m de long, {nombre(mur.H, 2)} m de haut et {nombre(mur.e * 100, 0)} cm d'épaisseur.

### Données

- Béton armé : γ = {POIDS_VOLUMIQUE_BA} kN/m³ (EN 1991-1-1, tableau A.1).
- Maçonnerie de blocs pleins : γ = {nombre(mur.gamma, 0)} kN/m³ (hypothèse de l'énoncé) <AVerifier note="Le poids d'une maçonnerie dépend des blocs et du mortier : il se lit sur la fiche du fabricant." />.

### Ce que tu rends

1. Pour chaque élément : volume, poids total, charge (kN/m² ou kN/m), avec la formule et les unités.
2. Pour chaque élément : un **contrôle de tête** avec des données arrondies.
3. Le **total** des trois poids propres, comparé à la règle de l'art de {nombre(CHARGE_GLOBALE_NIVEAU, 0)} kN/m² par niveau.
4. Une conclusion de deux lignes pour le bureau d'études.

<Encadre type="attention">
Ne mélange pas les cm et les m : les épaisseurs sont données en cm, les calculs se font en m (N0.3.2).
</Encadre>

</Page>

<Panneau n={1} titre="Volume" icone="quantites" couleur="encre">
Toutes les cotes en mètres, puis $V = L \times b \times h$ (m³).
</Panneau>

<Panneau n={2} titre="Poids" icone="charges" couleur="brique">
$P = \gamma \times V$ (kN), avec γ et sa source.
</Panneau>

<Panneau n={3} titre="Charge répartie" icone="calcul" couleur="acier">
Dalle : $g = \gamma e$ (kN/m²). Poutre et mur : $g = \gamma b h$ (kN/m).
</Panneau>

<Panneau n={4} titre="Contrôle de tête" icone="verification" couleur="validation">
Données arrondies à un chiffre significatif, calcul de tête, écart : moins de 50 % = même ordre de grandeur.
</Panneau>

<Panneau n={5} titre="Bilan et conclusion" icone="retenir" couleur="terre" large>
Additionne les trois poids, compare à la règle de l'art, puis écris deux lignes claires : valeurs retenues, hypothèses à confirmer.
</Panneau>

<Etape n={2} titre="Le total et la règle de l'art">

Total : **{grandeur(bilan.total, 0, 'kN')}**. Règle de l'art : {nombreCourt(Sdalle)} m² × {nombre(CHARGE_GLOBALE_NIVEAU, 0)} kN/m² = {grandeur(bilan.estimationRegle, 0, 'kN')}. Écart : **{pct(bilan.ecart)}** {memeOrdre(bilan.ecart) ? '→ même ordre de grandeur ✓' : '→ à revoir ✗'}.

<Note>Pourquoi un total plus faible que la règle ? La règle de l'art compte aussi les charges d'exploitation, les revêtements et les autres murs : un poids propre seul un peu inférieur est normal.</Note>
